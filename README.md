# Proyecto Capstone – Ciencia de Datos (SpaceX Falcon 9)

Este proyecto analiza los lanzamientos del cohete Falcon 9 de SpaceX con el objetivo de predecir el éxito del aterrizaje del primer propulsor.

## Metodología
- Recopilación de datos usando la API de SpaceX
- Web Scraping desde Wikipedia
- Limpieza y procesamiento de datos
- Análisis Exploratorio de Datos (EDA)
- Análisis con SQL
- Visualización interactiva (Folium y Plotly Dash)
- Modelos de Machine Learning

## Herramientas
Python, Pandas, NumPy, BeautifulSoup, SQL, Folium, Plotly Dash, Scikit-learn
